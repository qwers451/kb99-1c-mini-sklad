# Мини-Склад

Учебная конфигурация для 1С 8.3.27 и новее.

Готовый файл конфигурации: [конф.cf](configuration/конф.cf).

Внутри: справочники «Товары» и «Контрагенты», документы «Поступление» и «Реализация», регистр остатков и подсистема «Мини-Склад». Формы стандартные, движения документов, приход и расход товаров.

## Как открыть

1. Создайте пустую информационную базу и откройте её в Конфигураторе.
2. Выберите **Конфигурация - Открыть конфигурацию**, затем **Загрузить конфигурацию из файлов…** и укажите папку `configuration`.
3. Нажмите **F7**, примите изменения и запустите **1С:Предприятие**.
4. Откройте раздел **Мини-Склад**.
