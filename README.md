# Мини-Склад

Учебная конфигурация для 1С 8.3.27 и новее.

Готовый файл конфигурации: [конф.cf](configuration/конф.cf).

Внутри:

- справочники «Товары» и «Контрагенты»;
- документы «Поступление» и «Реализация» (в реализации есть цена и сумма);
- регистр остатков «Остатки товаров» и регистр оборотов «Продажи товаров»;
- СКД-отчёт «Обороты по товарам»: остаток на начало, приход, расход, остаток на конец, сумма продаж за период;
- печатная форма «Товарная накладная» — кнопка в форме реализации;
- подсистема «Мини-Склад».

Формы стандартные.

## Как открыть

1. Создайте пустую информационную базу и откройте её в Конфигураторе.
2. Выберите **Конфигурация - Открыть конфигурацию**, затем **Загрузить конфигурацию из файлов…** и укажите папку `configuration`.
3. Нажмите **F7**, примите изменения и запустите **1С:Предприятие**.
4. Откройте раздел **Мини-Склад**.

## Проверки

Сценарии в `tests/` запускаются в отдельной тестовой базе как серверный общий модуль. Они создают тестовые данные, поэтому в рабочей базе их запускать нельзя.

- `stock-control.bsl` — контроль остатков при проведении реализации.
- `practice-registers-report.bsl` — демо-данные за октябрь 2026, сверка остатков на дату, отчёт СКД и печатная форма.
